## 🧬 Sobre Mim

Sou Desenvolvedor Java focado em **Back-end, Arquitetura de Microsserviços, Mensageria Assíncrona e Sistemas Distribuídos**.

Tenho uma trajetória multidisciplinar: iniciei minha jornada acadêmica graduando-me em **Biomedicina pela Universidade Estadual de Londrina (UEL)**, base que desenvolveu meu forte raciocínio analítico, metodologia científica e rigor técnico na resolução de problemas complexos. Em seguida, migrei com entusiasmo para a área de tecnologia formando-me em **Análise e Desenvolvimento de Sistemas (UniFil)**.

* 💼 **Atuação Atual:** Desenvolvedor Back-end Java (desde out/2023), projetando soluções com o ecossistema Spring Boot, integrações assíncronas e bancos de dados relacionais e NoSQL, sob padrões modernos de engenharia de software.
* 🛠️ **Trajetória em T.I.:** Iniciei em 2022 no suporte técnico / Service Desk, consolidando comunicação assertiva, foco no cliente e resolução ágil de incidentes.
* 🎓 **Formação & Especializações:** Graduado em **ADS (UniFil)** e **Biomedicina (UEL)**. Capacitação corporativa intensiva na **Academia Java Atos-UFN**, especializações na **DevSuperior** (Java Spring Professional, Java Expert & POO com foco em DDD, Microsserviços, Testes e OAuth2/JWT), além de capacitações em Clean Code, TDD, Microsserviços e mensageria (RabbitMQ) pela **Alura** e ecossistema front-end moderno (React & TypeScript) pela **Rocketseat**.

## 🚀 Projetos em Destaque (Foco em Java)

### 🛒 [E-Commerce Microservices Platform (ecommerce-ms)](https://github.com/luizspolador/ecommerce-ms)
Plataforma completa de comércio eletrônico baseada em arquitetura de microsserviços orientada a eventos (**Event-Driven Architecture - EDA**), com persistência poliglota, resiliência distribuída, segurança de ponta a ponta e **100% de cobertura de testes automatizados**.
* **Linguagem & Frameworks:** Java 21 LTS com Virtual Threads (Project Loom), Spring Boot 4 e Spring Cloud (Eureka Discovery, Spring Cloud Gateway reativo WebFlux e Config Server).
* **Mensageria & Resiliência:** RabbitMQ (Topic Exchanges, Dead Letter Queues - DLQ), Transactional Outbox Pattern e Circuit Breaker/Retry com Resilience4j.
* **Persistência Poliglota:** MongoDB (catálogo de produtos), PostgreSQL (pedidos e IAM) e MySQL (estoque e projeções locais CQRS).
* **Segurança & Qualidade:** Keycloak (OAuth2, OpenID Connect, JWT, RBAC), 100% de cobertura de testes com JUnit 5, Mockito e JaCoCo; observabilidade com OpenTelemetry e Grafana LGTM.

### 📦 [DS-Commerce - Plataforma E-Commerce API](https://github.com/luizspolador/Projeto-DS-Commerce)
API RESTful completa e robusta de comércio eletrônico desenvolvida durante a formação Java Spring Professional (DevSuperior - Prof. Nélio Alves), estruturada sob boas práticas de engenharia de software e padrões corporativos.
* **Linguagem & Frameworks:** Java 17, Spring Boot 3, Spring Data JPA, Spring Security e Maven.
* **Arquitetura em Camadas & Domínio Rico:** Separação estrita de responsabilidades entre Controllers REST, Camada de Serviço (regras de negócio e orquestração de transações), Repositórios de Dados e Entidades com modelagem baseada em **Domain-Driven Design (DDD)**.
* **Encapsulamento com DTOs:** Transferência de dados via DTOs (*Data Transfer Objects*) imutáveis e desacoplados da camada de persistência (ORM), assegurando proteção contra manipulação indevida e redução de overhead.
* **Validação & Tratamento de Exceções Centralizado:** Validações declarativas com **Bean Validation** nos payloads de requisição e arquitetura global de exceções via `@ControllerAdvice`, tratando falhas de integridade, recurso não encontrado e validação com status HTTP semânticos (400, 404, 422).
* **Segurança & Controle de Acesso:** Implementação de controle de acesso e autenticação stateless com **OAuth2 e tokens JWT**, suportando diferentes perfis de usuário (Client e Admin).
* **Ambiente de Testes com Postman:** Mapeamento completo dos endpoints em Coleção Postman com variáveis de ambiente configuradas para alternância fluida entre ambientes de desenvolvimento e homologação.

### 🧪 [Java Expert - Desafios & Testes Automatizados](https://github.com/luizspolador/java-expert-curso-desafios-devsuperior)
Repositório centralizador de desafios práticos avançados da formação Java Expert (DevSuperior), com ênfase rigorosa em testes automatizados, TDD, cobertura de código e boas práticas de integração contínua.
* **Linguagem & Frameworks:** Java, Spring Boot, Spring Security, JUnit 5, Mockito, JaCoCo, MockMvc e RestAssured.
* **Testes Unitários & Mocking Avançado:** Implementação sistemática de testes com **JUnit 5** e **Mockito**, empregando *Fixtures* (`@BeforeAll`, `@BeforeEach`) e **Factory Pattern** para instanciação padronizada de entidades e DTOs, garantindo manutenibilidade e isolamento.
* **Cobertura Completa por Camadas:** Testes cobrindo rigorosamente Repositories, Services e Controllers na API DS-Catalog e validação de cobertura com **JaCoCo** nos serviços do DSCommerce (AuthService, CategoryService, ProductService, UserService e OrderService).
* **Testes de Integração & Autenticação Dinâmica:** Testes de integração em fluxos protegidos com **OAuth2/JWT**, incluindo desenvolvimento da classe utilitária `TokenUtil` para geração dinâmica de tokens Bearer em requisições de teste.
* **Testes de API com MockMvc & RestAssured:** Validação end-to-end de contratos HTTP, headers, status codes e payloads JSON utilizando **MockMvc** e **RestAssured** em portas e serviços isolados.
* **Fluxos de Negócio & Auditoria:** Implementação e testes de regras de autenticação, recuperação de senha via SMTP (Gmail) e resolução do usuário logado no contexto de segurança.
